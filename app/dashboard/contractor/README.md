# Contractor Dashboard

**Status:** Scaffolding only — full implementation deferred to future OpenSpec proposal.

## Planned Functionality

The Contractor dashboard will include:

1. **Quoting** — View available jobs and submit quotes
2. **Job Scheduling** — Schedule date/time to start work
3. **Work Order Management** — View assigned jobs, update status, add notes
4. **Site Access** — View property access details, key collection info
5. **Invoicing** — Submit invoices for completed work
6. **Communication** — Communicate with management/property managers
