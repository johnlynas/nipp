# Interactive Calendar

## Overview

An interactive, multi-view calendar component for the Property NI portal enabling all user classes to view, create, edit, and manage organization-scoped calendar events. Supports month, week, day, and multi-year views with drag-and-drop rescheduling, event detail modals, quick-add via sidebar or right-click context menu, and recurring events (weekly through annually).
