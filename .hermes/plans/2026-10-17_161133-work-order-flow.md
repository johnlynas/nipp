# Work Order Flow Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add a super-admin-managed Work Order workflow (work orders → RFQ emails →
quotations → assignment → completion → invoice → payment) with read-only tenant
views, on top of the existing global Contractors directory.

**Architecture:** Four new org-scoped Prisma tables (`WorkOrder`, `WorkOrderNote`,
`Quotation`, `Invoice`) with RLS + app-layer tenant extensions; four full-CRUD
services whose writes are `requireSuperAdmin`-gated and executed inside a tenant RLS
context pinned to the row's org (RLS `WITH CHECK` requires it); super-admin REST
routes for mutations, tenant read routes under `/api/organizations/[orgId]/…`; plain
nodemailer emails (same pipeline as Google OIDC invites, no magic URLs); an hourly
deadline-scan handler on the existing job scheduler. Frontend: CRUD admin pages +
read-only tenant pages.

**Tech Stack:** Next.js 15 App Router, Prisma 6 (PostgreSQL RLS), Vitest, Bree
job scheduler, nodemailer, @tanstack/react-query. **No new npm dependencies.**

**Companion design doc:** `documents/feature-planning-and-development/work-order-flow.md`
(READ IT FIRST — it contains the resolved decisions D1–D10 and state machine this plan implements).

// ============================================================
// Work Order Flow Models (org-scoped)
// Design: documents/feature-planning-and-development/work-order-flow.md
// ============================================================

/** Work order lifecycle. CLOSED = early closure pre-assignment (no funding etc.). */
enum WorkOrderState {
  CREATED
  OUT_FOR_QUOTES
  QUOTES_IN
  CONTRACTOR_ASSIGNED
  STARTED
  COMPLETE
  INVOICED
  FINISHED
  CLOSED
}

/** Quotation lifecycle within a work order. */
enum QuotationState {
  OPENED
  ACCEPTED
  REJECTED
  CLOSED
}

model WorkOrder {
  workOrderId    String         @id @default(cuid())
  description    String
  /** Email of the person/super admin who opened the work order (brief requirement). */
  openedBy       String
  /** User.id of the opener for actor integrity (nullable — super admins may open on behalf of orgs). */
  openedById     String?
  /** FK to Contractors; null until CONTRACTOR_ASSIGNED. */
  contractorId   String?
  /** Set when RFQ is sent; default deadline +7 days, configurable at send time. */
  quotesDue      DateTime?
  /** Set when the overdue alert fired (idempotency for the deadline job). */
  deadlineAlertAt DateTime?
  state          WorkOrderState @default(CREATED)

  organizationId String
  organization   Organization @relation(fields: [organizationId], references: [id], onDelete: Cascade)

  contractor Contractors? @relation(fields: [contractorId], references: [contractorId])

  notes   WorkOrderNote[]
  quotes  Quotation[]
  invoice Invoice?

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@index([organizationId, state])
  @@index([organizationId, quotesDue])
}

model WorkOrderNote {
  workOrderNoteId String  @id @default(cuid())
  workOrderId     String
  note            String
  /** Super admin user id who wrote the note (notes are super-admin managed). */
  createdById     String?
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt

  organizationId String
  organization   Organization @relation(fields: [organizationId], references: [id], onDelete: Cascade)

  workOrder WorkOrder @relation(fields: [workOrderId], references: [workOrderId], onDelete: Cascade)

  @@index([workOrderId])
}

model Quotation {
  quoteId      String         @id @default(cuid())
  workOrderId  String
  contractorId String
  /** Remote file link to the quotation, null until received. */
  quoteLink    String?
  /** Breakdown of the quote; null until received. */
  description  String?
  /** Quoted amount; null until received (filling it auto-moves the work order to QUOTES_IN). */
  price        Decimal?       @db.Decimal(12, 2)
  dueDate      DateTime
  state        QuotationState @default(OPENED)

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  organizationId String
  organization   Organization @relation(fields: [organizationId], references: [id], onDelete: Cascade)

  workOrder  WorkOrder   @relation(fields: [workOrderId], references: [workOrderId], onDelete: Cascade)
  contractor Contractors @relation(fields: [contractorId], references: [contractorId])

  @@unique([workOrderId, contractorId])
  @@index([organizationId])
}

model Invoice {
  invoiceId    String   @id @default(cuid())
  invoiceDate  DateTime
  /** 1:1 with WorkOrder. */
  workOrderId  String   @unique
  contractorId String
  invoiceLink  String?
  price        Decimal  @db.Decimal(12, 2)
  dueDate      DateTime

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  organizationId String
  organization   Organization @relation(fields: [organizationId], references: [id], onDelete: Cascade)

  workOrder  WorkOrder   @relation(fields: [workOrderId], references: [workOrderId])
  contractor Contractors @relation(fields: [contractorId], references: [contractorId])

  @@index([organizationId])
}

**Step 2 — Implementation skeleton:**

```ts
/** State machine: legal one-hop transitions (design doc §State Machine). */
export const WORK_ORDER_TRANSITIONS: Record<WorkOrderState, WorkOrderState[]> = {
  CREATED: ['OUT_FOR_QUOTES', 'CLOSED'],
  OUT_FOR_QUOTES: ['QUOTES_IN', 'CONTRACTOR_ASSIGNED', 'CLOSED'],
  QUOTES_IN: ['CONTRACTOR_ASSIGNED', 'CLOSED'],
  CONTRACTOR_ASSIGNED: ['STARTED'],
  STARTED: ['COMPLETE'],
  COMPLETE: ['INVOICED'],
  INVOICED: ['FINISHED'],
  FINISHED: [],
  CLOSED: [],
};

export const WORK_ORDER_STATES = Object.keys(WORK_ORDER_TRANSITIONS) as WorkOrderState[];
```

(OUT_FOR_QUOTES → CONTRACTOR_ASSIGNED is legal directly — design: not all contractors respond, org works with what arrives.)

Service object mirrors `ContractorService` structure: `create/getById/list/update/delete/transition`. `transition(id, to, opts, ctx)` steps:

1. `requireSuperAdmin(ctx)` (only for non-read ops).
2. Load row (with platform or tenant context as applicable); NotFound if absent.
3. Guard `WORK_ORDER_TRANSITIONS[row.state].includes(to)` else
   `throw new ValidationError(`Illegal transition ${row.state} -> ${to}`)`.
4. One `tenantDb.$transaction` with the side effects from design §State Machine (quotesDue, quote rows + OPENED states, contractorId + ACCEPTED/REJECTED, INVOICED requires existing invoice, FINISHED requires `opts.paid !== true`, CLOSED flips OPENED quotes to CLOSED).
5. AFTER commit: call `sendWorkOrderRfq` (Task 9) for OUT_FOR_QUOTES; log via `logger.info`.

Route calls the service inside a tenant RLS context pinned to the row's org (see design §Tenant Isolation — mutations run under `withRLSContext` scoped to `row.organizationId`, NOT pure platform context, because policy `WITH CHECK` fails writes without `app.current_org_id`).
